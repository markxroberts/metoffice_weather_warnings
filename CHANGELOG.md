# Changelog

## 0.1.9

- Add a Current warning sensor for the highest-severity active warning.
- Keep Next warning exclusively for the earliest upcoming warning, including its start/end sensors.
- Expose independent warning details on Current warning and Next warning.
- Retain the calendar and existing warning lifecycle behavior.

This repository publication imports the original v0.1.9 distribution, adds installation documentation, excludes generated bytecode, and aligns the internal version constant with the manifest. No new cancellation handling is introduced.

### Changes included since the repository's 0.1.3

- **0.1.4:** Enrich warnings with further details, last-updated timestamps and update reasons from linked warning pages.
- **0.1.5:** Centralize stable entity unique IDs, recognize singular/plural detail headings, and retry empty detail results.
- **0.1.6:** Stop further details before the feedback section.
- **0.1.7:** Handle GMT/BST labels and UK civil time in detail timestamps.
- **0.1.8:** Correct compact RSS validity times to UTC for accurate GMT/BST display.
